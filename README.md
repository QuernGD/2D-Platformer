# 2D Platformer

A Mario-style 2D platformer for iOS, built entirely with Claude Code in about 20 minutes.

No Swift was written by hand. Every line — the physics engine, tile collision, enemy AI, camera system, touch controls, menus, and level design — was generated by AI.

## What It Is

A side-scrolling platformer with Mario-accurate physics: acceleration-based movement, two-phase gravity for variable jump height, coyote time, jump buffering, enemy stomping, coins, question blocks, and a proper death/lives system. 2,000+ lines of Swift across 12 files.

## How It Plays

On-screen D-pad and A/B buttons. Hold a direction and tap jump simultaneously — full multi-touch support. Run through a hand-designed level with gaps, pipes, staircases, floating platforms, goombas, coins, and question blocks. Reach the flagpole to complete the level.

## How It Was Built

1. Fed Claude Code a detailed physics reference based on the original Super Mario Bros. NES ROM disassembly — actual gravity values, acceleration curves, subpixel movement, and forgiveness mechanics
1. Claude Code generated the entire project in two passes: core gameplay first, then menus and polish
1. Built as an unsigned IPA via GitHub Actions, signed on-device with Feather/Esign

## Tech

- Swift + SpriteKit — no SwiftUI, no third-party dependencies
- Custom physics engine in `update()` — no SKPhysicsBody
- Split-axis AABB tile collision
- Fixed timestep game loop with accumulator
- All visuals are colored shapes — no image assets
- Unsigned IPA built via GitHub Actions CI

## Physics Details

The physics aren’t a rough approximation — they’re modeled on actual NES data:

- Two-phase gravity: weak while rising with jump held (~3.5x weaker than falling gravity)
- Acceleration-based movement with doubled skid deceleration when reversing
- Full air control with zero air friction
- Jump velocity scales with running speed
- Coyote time (100ms grace period after walking off a ledge)
- Jump buffering (100ms input buffer before landing)
- Enemy stomp detection with position + velocity check and variable bounce height
